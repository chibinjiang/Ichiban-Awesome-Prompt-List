# 超写实人物镜面自拍｜浅蓝碎花短裙与极低位宽腿深蹲

## Prompt

```text
超写实室内镜面自拍摄影，竖版约 9:16，一名年轻成年东亚女性在极简卧室/更衣区的大型落地镜前采用极低位宽腿深蹲姿势自拍。采用约 35~50mm 等效手机镜头，人物距离镜面约 1–1.4 米，机位接近人物胸腹高度并轻微向下。构图从头顶完整拍到双脚，人物位于画面中央偏下，占画面高度约 78–84%；上方保留较大面积浅米白空墙，左右可见窄灰色镜框，下方为浅灰米色短绒地毯。保持真实手机镜面自拍透视，不使用鱼眼，不做明显背景虚化。

人物为年轻成年东亚女性，整体是紧凑、丰满、明显沙漏型的自然体型。骨架中等偏小，肩部适中偏窄，胸廓本身不宽，上半身明显丰满；腰部短而明显收束，骨盆与髋部较宽，臀胯饱满，大腿根部非常丰满厚实。身体比例重点为：丰满上身＋短腰＋明显腰胯差＋宽髋＋厚实丰满大腿。不要生成长躯干、纤细模特身材、窄胯细腿、健美肌肉型或“巨臀＋细腿”比例。

人物采用真正的极低位宽腿深蹲：双脚分开较宽，双膝向左右两侧明显打开，骨盆下降到接近脚踝高度；大腿几乎横向展开并高度屈曲，小腿接近竖直，脚掌完整贴在地毯上或脚跟仅轻微抬起。深蹲使臀胯、大腿根和大腿产生自然软组织压缩，大腿视觉上显得短、宽、厚实。整个姿态必须低、宽、紧凑，不要半蹲、跪姿、弓步或一条腿单独抬高。

上半身基本保持直立，仅轻微向人物左侧倾斜。骨盆接近正对镜面，躯干轻微扭转形成柔和 S 型。人物右手举一部白色智能手机至脸部右侧，手机竖直，遮住一部分右眼和右侧脸颊；右肘弯曲，手指自然展开。人物左臂从肩部自然垂下，左手位于双腿中间靠近膝盖下方，手指向地面放松伸展。不要双手都举起，不要叉腰。

人物头部轻微向人物左侧倾斜，下巴略微收起，双眼看向镜中自己的手机屏幕，表情安静、略带轻微嘟嘴感，不露齿笑。

人物留乌黑色长直发，长度约到胸部以下，发量自然偏浓密。头顶近中分，额前为轻薄齐眉空气刘海，刘海分束细碎，两侧保留较长脸侧发丝。长发沿肩膀和胸前自然垂落，发尾轻微内弯，不要大卷发、短 Bob 或高马尾。

脸型小巧偏鹅蛋形，下颌柔和，肤色白皙偏暖。深棕色杏仁眼，双眼皮自然，眼线细长略微上扬，睫毛清楚；眉毛自然偏细，鼻梁小巧顺直，嘴唇自然丰满、裸粉豆沙色。妆容清淡，双颊带一点柔和粉色，皮肤保留真实毛孔和轻微肤色变化，不要过度磨皮。

颈部佩戴一条非常细的纯黑色 choker，贴合颈部，结构简单，没有大型吊坠。

人物穿一件浅天蓝色超短贴身吊带连衣裙 / camisole mini dress。裙子材质为柔软弹力棉或细针织，整体非常贴身，顺着胸部、腰部、髋部自然包覆。底色为低饱和婴儿蓝/浅天空蓝，表面均匀分布大量非常小的白色雏菊/碎花图案，花心可带一点淡黄色。图案尺寸很小、间距密集但自然，不要变成大花印花或波点。

肩带非常细，为浅蓝或白色细带。胸口为低圆领/浅 U 形领口，领口周围带一圈很细的白色蕾丝花边；胸前中央有一枚小巧白色蝴蝶结。上身区域贴合身体并产生自然拉伸，腰部明显收紧。

裙摆非常短，结束在大腿根部附近，坐蹲姿势下沿髋部向两侧轻微上移并形成自然横向褶皱。裙摆不能变成长裙、A 字裙或蓬蓬裙，要保持贴身超短小吊带裙结构。

双腿穿纯白色大腿袜/过膝长袜，袜口位于大腿中上部，形成一圈较宽的纯白色袜边。袜子材质为柔软半厚针织，基本不透明，但能表现细腻织物纹理。深蹲时袜口随着丰满大腿自然撑开，形成轻微但真实的压力感，不要勒出夸张凹痕。袜子从大腿一直覆盖到脚趾，脚部没有鞋子。不要生成透明丝袜、网袜、蕾丝袜或短袜。

背景极简：大面积暖白/浅米灰色墙面，占据画面上半部；墙面基本没有家具和装饰。地面铺浅灰米色短绒地毯，纹理细密均匀。左右仅保留落地镜细窄边框以及非常少量墙角结构，不加入床、沙发、衣柜、桌子或大量杂物。

光线为白天柔和自然窗光＋室内环境光，人物脸部、肩颈、胸前和腿部曝光柔和均匀。整体色调偏奶油白和浅冷灰，人物肤色自然偏暖，浅蓝裙子成为画面唯一明显色彩。阴影非常轻，不使用手机强闪光，不使用暖黄夜灯，不使用电影级侧逆光。

画面呈真实高质量手机镜面自拍质感：自然锐化、轻微手机 HDR、少量细腻数码颗粒，人物和背景基本都在焦内。不要商业棚拍质感，不要夸张磨皮，不要 CG 感。

重点锁定：大面积浅色空墙＋落地镜自拍＋极低位宽腿深蹲＋双膝明显向两侧打开＋双脚贴地＋短躯干＋丰满上身＋明显细腰＋宽髋＋非常丰满厚实大腿＋长黑直发＋轻薄空气刘海＋黑色细 choker＋浅蓝碎白花超短细肩带贴身连衣裙＋白色蕾丝领边和胸前小蝴蝶结＋纯白大腿袜＋右手举白色手机遮部分脸＋左手自然垂在双腿之间＋浅灰地毯＋柔和白天自然光＋真实手机镜面自拍。

避免：站姿、半蹲、跪姿、弓步、膝盖并拢、臀部位置过高、超长腿、细腿、窄髋、长腰、健美肌肉型、极端蜂腰、短发、无刘海、大卷发、黑色裙子、纯蓝无花纹裙子、大花图案、长裙、百褶裙、牛仔裙、黑丝袜、透明丝袜、鞋子、高跟鞋、复杂卧室背景、暖黄夜景、强闪光、背景严重虚化、鱼眼、超广角畸变、塑料皮肤。
```

## 使用说明

- 这是人物写实摄影类 Prompt Card，建议先验证构图和姿势，再验证服装细节。
- `年轻成年` 是必要的年龄约束；不要删除成年限定。
- 如果模型对极低位深蹲的空间关系理解不稳定，建议增加姿势参考图或使用 OpenPose / ControlNet。
- 该 Prompt 当前标记为 `experimental`，需要经过多模型、多次生成和回归测试后再升级为 `stable`。
